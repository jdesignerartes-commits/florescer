# 🌿 Florescer

> **Pequenas ações diárias constroem uma vida equilibrada.**

## Visão do Projeto

Florescer é um aplicativo independente desenvolvido no Claude Code para ajudar pessoas a organizarem sua rotina de forma leve, acolhedora e consciente.

Este **não é um aplicativo de produtividade corporativa**.

O foco é ajudar a construir uma rotina saudável através de pequenos hábitos diários, acompanhando também humor, energia, gratidão e evolução pessoal.

A produtividade existe apenas como um indicador da rotina, nunca como forma de cobrança.

---

# Objetivo

Criar um aplicativo que una:

- organização da rotina;
- hábitos;
- bem-estar;
- humor;
- energia;
- equilíbrio;
- autocuidado;
- constância.

O aplicativo deve transmitir calma, leveza e acolhimento.

Nunca deve passar a sensação de cobrança ou pressão.
